# Frontend-only scope

Follow the team repository root `AGENTS.md` and `docs/` guidelines. This directory contains only React/TypeScript/Vite frontend source, frontend tests, and safe configuration.

Use Tailwind, accessible shadcn-style components, Recharts, React Router, TanStack Query, and Lucide with deep navy, blue, slate, light-neutral colours. The demonstration must not claim verified DRUNIX commits or financial integrations without backend evidence. Frontend role switching is not secure authentication.

Do not add backend code, chaincode or credentials here. Run `npm test` and `npm run build` from `frontend/`.
